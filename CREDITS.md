# Sources and attribution

The author code implements the methods and experiments in *Multivariate conditional randomisation tests with unknown covariate parameters*.

The distillation CRT (dCRT) comparator is adapted from Molei Liu's [Distillation-CRT repository](https://github.com/moleibobliu/Distillation-CRT), associated with Liu, Katsevich, Janson, and Ramdas. The adapted functions are in `R/dcrt.R` and in the application-specific baseline implementations. No explicit software licence was found in the inspected upstream source; this local repository does not assign a new licence to that code.

Application data sources and preparation details are in [data/README.md](data/README.md). R and Python packages are installed dependencies and retain their upstream licences. This local candidate has no blanket open-source licence.
