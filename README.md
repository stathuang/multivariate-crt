# Replication code for multivariate conditional randomisation tests

This private repository holds the prepared replication code for **Multivariate conditional randomisation tests with unknown covariate parameters** by Xiaotong Lin, Jie Xie, Fangqiao Tian, and Dongming Huang.

## Download and run

Download [the complete code archive](jrssb-github-candidate-20261126-r3.zip), verify it against [SHA256SUMS](SHA256SUMS), and extract it. Its directory structure must be preserved. Start with the archive's README.md for installation and commands, RESULT_MAP.md for the manuscript figures and tables, and VALIDATION.md for the computations actually checked.

The archive is the unchanged code distribution prepared on 26 November 2026. It includes the analysis code, adopted computation records, reconstruction scripts, dependency specifications, and provenance. Figure and table references use the current manuscript numbering.

## Peer-review materials

The separate review archive, `jrssb-review-20261126-r3.zip`, also includes the exact application input snapshots and the historical dCRT source copy. It is prepared as a separate submission attachment. Figshare sharing is currently deferred. This GitHub archive excludes the raw application inputs and the full historical dCRT script; its README provides data acquisition instructions. No new experiments were run for this upload.
