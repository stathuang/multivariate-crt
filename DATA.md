# Data preparation details

The README contains the download, file-layout, and preparation commands. Data sources are Yahoo Finance and NCBI GEO GSE2034. The review package contains the seven exact snapshots; the GitHub candidate contains their checksums and an explicit downloader. Five historical files were verified against the fixed public GGMtest revision, and the decompressed GEO matrix was verified against NCBI. The complete DIA response uses the preserved 23 October 2026 snapshot.

Stock preparation retains the accepted 103-stock matrix, graph, and target sets. It forms 92 complete five-trading-day response windows from all 460 DIA returns and refits the null models with seed 2023. `scripts/check-stock-transform.R data/raw/Stock` also reconstructs the full stock transformation from the saved price arrays and exports its parameters, including the MMM/MO Box–Cox exponents 1.4 and 1.5.

Breast-cancer preparation reads the processed GEO expression matrix rather than reconstructing it from CEL files. It matches the first 60 probes in the original ordered list, applies order normalisation across all 286 patients, retains 209 ER-positive patients, and reproduces the seed-2023 selection and fitted null. The result has three background probes, 18 targets, and response counts 152, 52, and 5. The marker source is Wang et al. (2005), *Gene-expression profiles to predict distant metastasis of lymph-node-negative primary breast cancer*, Lancet 365:671–679, Table 3, DOI https://doi.org/10.1016/S0140-6736(05)17947-1.

The public `GSE2034-PI.csv` exactly matches the supplied clinical table. This verifies access to the adopted table; the earliest conversion of clinical records into that CSV has not been reconstructed. The table has relapse/follow-up time and a brain-relapse flag, but no separate brain-relapse date. Category 2 means relapse within 48 months with the flag present. Selection depends on the outcome, and the null experiment holds the selected target and background sets fixed.

Preparation writes `data/local/stock.rds`, `data/local/bcr_erplus60.rds`, the corresponding engine caches, and `data/local/IMPORT.csv`. Fresh preparation and import refuse to overwrite existing files. Prepared objects can alternatively be imported with `Rscript --vanilla scripts/prepare-data.R import /path/to/prepared-directory`. Use the supplied distribution ZIPs for transfer; an analysis working directory can additionally contain patient-level or market-data outputs.
